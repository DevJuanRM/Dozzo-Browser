# 🚀 Guía Oficial de Instalación de Dozzo Browser en PC (Windows)

Bienvenido a **Dozzo Browser**, el navegador de última generación ultra rápido, 100% privado con adblocker integrado, Binance Crypto Hub y Dev Studio.

---

## 📦 1. Descarga del Instalador

Descarga siempre la versión más reciente desde el enlace oficial de GitHub Releases:
🔗 **[Descargar Dozzo Browser para Windows (GitHub Releases)](https://github.com/DevJuanRM/Dozzo-Browser/releases/latest)**

Tipos de instaladores disponibles:
- **`Dozzo-Browser-Setup-x.x.x.exe`**: Instalador estándar de Windows con creación automática de accesos directos en Escritorio y Menú Inicio.
- **`Dozzo-Browser-Portable.exe`**: Versión portable que se ejecuta sin instalar nada en el sistema (ideal para memorias USB).

---

## 🛡️ 2. Aviso de Windows SmartScreen ("Windows protegió su PC")

Al ser un software nuevo e independiente de código abierto, Microsoft Windows SmartScreen puede mostrar una advertencia azul que dice:

> **"Windows protegió su PC"**  
> *Microsoft Defender SmartScreen impidió el inicio de una aplicación no reconocida.*

### ¿Cómo continuar? (Es 100% seguro)
1. En la ventana azul de advertencia, haz clic en el texto subrayado: **"Más información"**.
2. Aparecerá un nuevo botón abajo a la derecha: haz clic en **"Ejecutar de todas formas"**.
3. El instalador oficial de Dozzo Browser se abrirá de inmediato.

---

## ⚙️ 3. Pasos de Instalación

1. Ejecuta el archivo `Dozzo-Browser-Setup-x.x.x.exe`.
2. Elige si deseas instalarlo para tu usuario actual o para todos los usuarios del PC.
3. Puedes elegir la ruta de instalación o dejar la ruta recomendada por defecto.
4. Haz clic en **Instalar**. En pocos segundos Dozzo Browser se abrirá automáticamente.

---

## 🔄 4. Actualizaciones Automáticas y Detección de Versiones Anteriores

Dozzo Browser incluye un sistema inteligente de verificación de versiones:
- **Detección automática en segundo plano**: Cada vez que abres el navegador, este verifica si existe una versión más nueva en GitHub.
- **Aviso proactivo**: Si estás usando una versión anterior, Dozzo te mostrará una notificación elegante con las novedades de la nueva versión y el botón para descargarla o aplicarla en 1-clic.
- **Sin pérdida de datos**: Todas tus pestañas abiertas, marcadores favoritos y configuraciones se conservan intactas entre actualizaciones.
- **Comprobación manual**: En cualquier momento puedes abrir `Ajustes (⚙)` > `Versión y Actualizaciones` y hacer clic en **"Comprobar actualizaciones ahora"**.
